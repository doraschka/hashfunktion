Merkmal 2 Determinismus

Gleiche Eingabe = Immer exakt gleiche Ausgabe

Eingabe heute "Geheim123" a35f...89e2
Eingabe morgen "Geheim123" a35f...89e2

Hashfunktionen sind deterministisch: Für denselben Eingabetext wird absolut jedes Mal derselbe identische Hashwert erzeugt.

Merkmal 3 Einwegfunktion (Preimage Resistance)

Die Einbahnstraße der Kryptographie

Vorwärts: Kinderleicht Eingabe → Hash berechnen
Rückwärts: Unmöglich Hash → Eingabe berechnen

Vom Hashwert darf keine Rückrechnung möglich sein. Es handelt sich um eine echte mathematische Einwegfunktion.

Merkmal 4 Lawineneffekt (Avalanche Effect)

Winzige Änderung = Völlig neuer Hash

Eingabe 1: "Hallo"
185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969
Nur 1 Buchstabe geändert ('H' → 'h')
Eingabe 2: "hallo"
d3751d38490d1075be34c91901c89004550302b1f09e25d2a93eb8351586ec45

Die kleinste Änderung beim Eingabetext verursacht eine völlig andere Ausgabe (ca. 50 % aller Bits ändern sich unvorhersehbar).

Merkmal 5 Kollisionsfreiheit (Collision Resistance)

Keine zwei Eingaben führen zur selben Ausgabe

Eingabe A "Passwort123" Hash X
Eingabe B "BeliebigeDaten" Hash Y

Verschiedene Eingaben dürfen nicht zur gleichen Ausgabe führen. Bei SHA-256 gibt es $2^{256}$ Möglichkeiten – eine Kollision zu finden ist praktisch unmöglich.
