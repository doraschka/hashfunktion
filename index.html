Was ist eine Hashfunktion?

Eingabe (Beliebig lang) "Hallo Welt"
oder Buch/Datei (1 GB)
Hashfunktion
Ausgabe (Feste Länge) a35f...89e2
immer z. B. 256 Bit (SHA-256)

Egal wie groß die Eingabe ist – ob ein einzelnes Wort oder eine Bibliothek – eine Hashfunktion erzeugt daraus einen mathematisch berechneten, einzigartigen Fingerabdruck fester Länge.

Merkmal 1 Einweg-Eigenschaft (Preimage Resistance)

Die Einbahnstraße der Kryptographie

Vorwärts: Kinderleicht Eingabe → Hash berechnen
Rückwärts: Unmöglich Hash → Eingabe herausfinden

Es ist extrem schnell, den Hashwert einer Eingabe zu berechnen. Es ist jedoch praktisch unmöglich, aus dem Hashwert wieder auf die ursprüngliche Eingabe zurückzurechnen.

Merkmal 2 Der Lawineneffekt (Avalanche Effect)

Kleinste Änderung = Völlig neuer Hash

Eingabe 1: "Hallo"
185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969
Nur 1 Buchstabe geändert ('H' → 'h')
Eingabe 2: "hallo"
d3751d38490d1075be34c91901c89004550302b1f09e25d2a93eb8351586ec45

Ändert sich auch nur ein einziges Bit der Eingabe, verändert sich der resultierende Hashwert unvorhersehbar und zu ca. 50 % aller Stellen. Das nennt man den Lawineneffekt.

Merkmal 3 Kollisionsresistenz (Collision Resistance)

Keine zwei Eingaben haben denselben Hash

Eingabe A "Passwort123" Hash X
Eingabe B "BeliebigeDaten" Hash Y

Es darf praktisch unmöglich sein, zwei verschiedene Eingaben (A & B) zu finden, die exakt denselben Hashwert erzeugen. Bei SHA-256 gibt es 2256 Kombinationen – mehr als Atome im beobachtbaren Universum!

Sicherheitsmerkmale von SHA-256 im Überblick:

Feste Ausgangslänge

Erzeugt stets exakt 256 Bits (64 Hexadezimalzeichen), egal wie lang der Input ist.

Einweg-Eigenschaft

Mathematisch nicht umkehrbar. Aus dem Hash kann kein Klartext gewonnen werden.

Lawineneffekt

Jede minimale Änderung erzeugt einen völlig unähnlichen Hashwert.

Kollisionsresistent

Keine zwei unterschiedlichen Eingaben führen zum gleichen Hashwert.
